## What I learned / what did not work
- `npm install` downloads the packages listed in `package.json` into `node_modules/`, which is not published on Git because `.gitignore` excludes it.
- A component is a function that returns JSX; in JSX I write `className` instead of `class`, and I put JavaScript expressions between braces.
- The data array goes above the function (it runs once); the computed value goes inside the function, before `return`, so it is recalculated at every update.
- The counter is computed from the data (`exercitii.length` and `deFacut`) and updates by itself when I edit the array and save.
- A terminal opened outside the project folder fails on `cd frontend`; opening the project folder in VS Code fixes it.
- Deleting the demo files makes the page white with a 404 in the console until `main.jsx` imports `App.css` instead of `index.css`.
